# 学习管理系统（LMS）

一个纯前端、零依赖的学习管理系统单页应用，数据保存在浏览器 localStorage 中，可离线使用。

## 如何运行

**方式一（最简单）**：直接双击 `index.html` 用浏览器打开即可。

**方式二（推荐，本地服务器）**：

```bash
cd learning-management-system
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能清单

| 模块 | 说明 |
|------|------|
| 🏠 学习中心 | 今日学习进度/目标、连续打卡、课时统计、继续学习、近7天时长柱状图、待办速览、各课程进度 |
| 📖 全部课程 | 课程卡片、分类筛选、关键词搜索、学习进度条 |
| 课程详情 | 课程简介/统计、章节目录（可折叠）、课时列表（已完成/未完成状态） |
| 课时学习 | 图文/视频课时内容、课时目录侧边栏、上一课/下一课、标记学完（自动记入当日学习时长）、撤销学完 |
| 📊 学习统计 | 累计时长、完成课时/课程、14天学习时长图、各课程完成度、笔记与任务统计 |
| ✅ 学习计划 | 任务添加（标题+截止日期）、完成勾选、删除、逾期/今日截止提醒 |
| 📝 我的笔记 | 在课时页记录笔记、全站笔记汇总（按课程跳转）、删除 |
| ⚙️ 设置 | 昵称、每日目标分钟数、导出/导入 JSON 备份、重置演示数据 |

## 内置课程数据

系统内置 5 门课程作为演示数据，其中《Maven 基础》的「Maven 的安装」一课包含完整安装步骤（解压、配置本地仓库 `localRepository`、配置阿里云私服镜像、配置 `MAVEN_HOME` 环境变量），与课件要求一致。

## 数据说明

- 所有学习记录（进度、笔记、任务、每日学习时长、设置）保存在浏览器 `localStorage`，键名 `lms_v1`。
- 「设置 → 导出数据」可备份 JSON 文件，换浏览器/电脑时可通过「导入数据」恢复。
- 「重置为演示数据」会清空记录并恢复初始状态。

## 技术栈

原生 HTML / CSS / JavaScript（ES6+），无任何外部依赖、无构建步骤，hash 路由单页应用。

    └── app.js      # 路由、渲染与交互逻辑
